# Policy-Grounded Agent — Design Memo

**Purpose and authority.** This Python CLI retrieves Nimbus billing evidence, proposes structured model decisions, independently applies reviewed policy rules, and renders bounded replies. It exposes evidence, facts, missing checks, candidate errors, and final decisions per turn. Local account fixtures never perform real credit issuance or external handoff. All ten KB articles are retained; source hashes bind executable rules to reviewed text.

**Grounded and unresolved answers.** Rule 3 and KB-1004/1005 support $225 ÷ 30 × 11 = **$82.50**, without multiplying the three-line total again, and a request within 30 calendar days of restoration (day 14 here). Historical agent NOC confirmation is supplied transcript evidence, not a new lookup. The $75 Rule 2 goodwill ceiling does not govern this outage credit. KB-1004 establishes only the recurring-plan calculation base; no supplied rule establishes downstream tax or surcharge adjustment. The workflow states that gap and requests human clarification, without inventing a tax answer or routing policy. Missing fraud/history checks prevent authorization claims.

**Hardest hierarchy.** The narrow outage exception replaces the general cap but preserves Rules 4/5 escalation requirements. Eligibility, arithmetic, and action authority remain separate; unknown cannot become false or borrow verification from an explicit null. Ticket absence, unverifiability, and an unperformed check differ. The current original-policy implementation also conservatively applies invoice-dispute prerequisites to outage requests; this is a documented limitation for pure outage requests. Full-day arithmetic and half-up rounding are implementation conventions, not newly approved enterprise policy. Scenario-specific unresolved business decisions retain explicit boundaries.

**Current evidence.** Workflow-v11 passed the coordinator's 388-test local checkpoint; its real-model replay and fresh V3 acceptance are **unrun**. V10's six-turn Haiku adaptive/medium replay failed on turn 4 after one exhausted scope repair (18 calls, estimated $0.0119011, 77.203 seconds summed turn time). V11 corrects the optional action-quote contract and adds bounded repair feedback, but local tests do not establish recovery of that live failure. The earlier v8 original conversation passed seven scoped checks; independent v8 acceptance still produced no qualifying model (Sol-low 24/48 successes; Haiku-medium 34/48). Those versions remain distinct. Haiku adaptive/medium is the user-selected **development default, not a winner**. Paid testing is paused.

**Policy and measurement limits.** Frozen-v5 policy A/B completed 120 pairs per model: raw composite improved, but final composite fell by one for both Sol and Luna; the optimized policy was not promoted. The newer scenario policy has local checks but no completed new paid paired comparison. The original default policy remains. Native tax-claim restrictions enforce evidence coverage rather than prove autonomous model reasoning. Request omission, quote entailment, ambiguous bill-item identity, and added review latency remain limitations; failures and conservative stops stay in denominators.

**Next step.** Claude handoff preserves exact versions and failed runs. Resume API work only after explicit user authorization: freeze v11 inputs, replay the full conversation, run independent development regressions, then fresh held-out acceptance without exposing expected answers to models. Report raw and final correctness separately, mandatory-escalation recall, supported-answer completion, unsupported claims, technical failures, full-turn P95/P50, and cost per successful conversation. Rank accuracy, then speed, then price. A static report or finite local suite is not completed model acceptance or proof of zero hallucination.
